# SI Arena：网格圈地参赛提示词

请编写一份可直接上传 SI Arena 网格圈地游戏的 UTF-8 JavaScript 文件。只输出最终完整代码，不输出 Markdown 围栏或解释。

## 对局与胜负

- 40×30 网格上的两人对抗。坐标左上为 (0,0)，右为 x+1，下为 y+1，边界不可穿越。
- 开局各有 3×3 领地，其中心格是你的出生点；两个出生点关于中线对称，种子决定你在哪一侧。
- 固定打满 600 tick，没有提前结束；双方永不淘汰，被重置也照常继续。
- 每个 tick 双方看到同一张完整地图，然后同时行动。
- 600 tick 打满后按最终领地格数排名，多者获胜，相同则并列第一。

## 核心循环：外出画尾迹，回城圈地

- 头部在领地外每移动一格，走过的格子就成为你的尾迹；在外原地停留不延长尾迹。当前位于领地外的头部格也在尾迹里。
- 带着尾迹走进任意一格自己的领地即闭合。尾迹不需要绕成环，两端接上己方领地即可。
- 闭合的判定：把你现有领地和这条尾迹当作屏障，从地图边缘按四邻接洪泛，走不到的格子全部划归给你。闭合可以覆盖对手领地（哪怕对手正站在那格上），但不会因此重置对手；双方同一 tick 闭合重叠的格子保持原归属，原为中立的仍中立。
- 闭合结算后尾迹清空。领地不要求连通，断开的格子照常保留，任何一格己方领地都可以作为回城点。
- 尾迹完全暴露：对手的目标格落在你尾迹任意一格上，你这次外出就作废（见下一条）。每次扩张都在权衡圈多少面积与能否安全回城。

## 碰撞与重置

所有命中都用行动前（上一 tick 结算后）的位置与尾迹判定，双方同时结算：先算完所有命中，再统一执行。触发任一情况的一方被重置——尾迹全部清空、头部回到出生点、领地全部保留；该 tick 不移动、不闭合、不圈地，动作作废。

- 移动越界（不会自动转向）。
- 双方目标格相同，包括一方原地停留被走进；此时双方都重置。
- 双方交换位置；双方都重置。
- 移动进入自己的尾迹（原地停留在自己尾迹所在格不算）。
- 移动进入对手的尾迹：被重置的是尾迹的主人，踏入的一方不受影响。这是"切断"，也是主动进攻的基本手段。

补充：本 tick 新产生的尾迹从下一 tick 起才可被切断；被重置一方的落点若与对手本 tick 落点重合，双方都重置；若出生点领地已被对手圈走，重置会在出生点留下一格尾迹，下一 tick 可能再次被切断。领地降为 0 不会出局，但本局无法再靠回城增加领地，只能阻断对手扩张。

## 玩家接口

默认导出同步函数，每 tick 调用一次：

```js
export default function tick({ observation, Memory, sdk }) {
  return { type: "idle" };
}
```

- 返回 `{ type: "idle" }`（原地不动，仍会被碰撞、被切断）或 `{ type: "move", direction: "up" | "right" | "down" | "left" }`；不要返回额外字段。
- 不要修改 observation，世界不受你的观察对象影响。

## observation：每 tick 的完整地图

- `territory` 与 `trails`：长度 width×height 的一维数组，索引为 `y * width + x`；-1 表示无主或无尾迹，0、1 表示席位编号。
- `players` 按席位排列，每项含 `id`、`slot`、`alive`、`position: { x, y }`；`alive` 恒为 true（永不淘汰），`position` 是该方当前头部格。
- `spawns` 按席位排列，是该席位的出生点（开局 3×3 的中心），重置回到这里。
- `selfSlot`、`selfId` 标明你是哪一方；另有 `tick`、`width`、`height`、`maxTicks`、`rngState`。

## sdk：随参数提供的辅助函数（无需导入，均不预测对手动作）

- `directions`：方向常量数组。
- `homePath(observation)`：不经过自己尾迹的最短回城方向序列；已在领地内为 `[]`，无可达路线为 `null`。
- `threatDistance(observation)`：对手头部到你尾迹的最短步数，不可达为 `null`。
- `safeMoves(observation)`：不越界、不进自己尾迹、不进对手当前头部格的方向。
- `expansion(observation)`：从领地边界起步的矩形扩张方向序列。

这些都只是基础辅助，可以不用，自行实现更好的算法。

## Memory 与资源

- 每 tick 重建 JavaScript 环境，全局变量不跨 tick 保留；只有 JSON 对象 `Memory` 延续，把计划与状态写进 Memory。
- 默认预算：源码 256KiB、每 tick CPU 20ms、QuickJS 堆 32MiB、栈 256KiB、Memory 64KiB、动作输出 1KiB；以开发包 release.json 的 `resolvedLimits` 为准。
- 抛错、超时、非法动作或超限时：该 tick 按 idle 处理，本次对 Memory 的修改丢弃（上次成功的 Memory 保留），下一 tick 继续调用你。持续出错不会出局，只会一直浪费回合。

## 语言限制

不能使用 import、require、异步函数、Promise、网络、文件与 Node API；不要依赖 Date、现实时间或 Math.random。可用受限 console 输出调试日志（本地开发包可见，线上不收集）。

目标：在守住已有领地的前提下安全扩张、伺机切断对手尾迹，用更稳健的长期策略提高胜率。
